# 嘴替·催婚包 🍚

> 🧩 **[嘴替.skill](https://github.com/SilentFleetKK/zuiti-skill) 生态的场景子仓** · [装主仓解锁画饼/甲方/伴侣/前任等全部场景 →](https://github.com/SilentFleetKK/zuiti-skill)

**过年回家最难回的那句"你到底怎么想的"，这里有得体、有针、也有底气的三种回法。**

亲戚拿别人家孩子当尺子量你，爸妈半夜发来"不图你什么就一个心事"，饭桌上一句"眼光别太高"让全屋看你——催婚不是一条消息，是每年、每次聚会、每通电话的持久战。

这个包只干一件事：把长辈的潜台词翻译清楚，再替你回得**发得出去、守住你的人生节奏、明年还能回家吃饭**。

它先帮你分清眼前是**套路施压**还是**焦虑的爱**（这决定你该软还是该立），再给三档可以直接复制发送的回复：

- **体面版** —— 长辈挑不出错，围观亲戚说不出你不孝，你一个字没松口
- **绵里藏针版** —— 顺着关心往下说，把"你别催了"埋进孝顺话里
- **掀桌版** —— 把话挑明、节奏我定，但不撕破脸、不数落父母、不带脏字

> 嘴替.skill 的场景子仓。催婚这块最难，因为对面多半是真的爱你、也真的在施压——所以底线是：把节奏拿回来，但别把亲妈顶哭。

## 看效果

### Demo 1 · 三姨拿表妹当尺子量你

> **三姨**
> 你看你表妹孩子都两个了，你到底怎么想的？眼光别太高。

🎭 **潜台词翻译**
一句话叠两套：拿表妹当尺子量你（横向比较）+ 用"眼光别太高"把你的选择说成毛病（贬低）。核心是把"你没结婚"定义成需要向她交代的落后。**偏施压**——她图的是有得聊，不是真替你睡不着。
**误读风险：低。**

💬 **绵里藏针版**（推荐）
谢谢三姨惦记～表妹幸福是表妹的福气，我也替她高兴。我这边也挺好的，眼光倒不是高，是想找个真合适的，这事儿急不来，您说是吧。

📌 **发送建议**
爱比较的远亲，绵里藏针最稳：接住关心、把"急不来"轻轻放桌上，既没顶撞也没松口。

---

### Demo 2 · 妈妈半夜发来的那条长消息

> **妈妈**
> 王阿姨给你介绍了个男孩子，条件真的很好，见一面怎么了？妈不图你什么，就这一个心事。你别嫌我们烦，我跟你爸年纪都上来了。

🎭 **潜台词翻译**
这条**没有套路**，焦虑是真的，爱也是真的。她要的不是你立刻结婚，是"这事有人在管"的确定感。别当攻击去防御——她越被顶回去，越睡不着。
**误读风险：高。**这是笨拙的爱，不是控制，别把亲妈写成反派。

💬 **绵里藏针版**（推荐）
妈，人我可以见。但有件事想跟你说清楚：我不是不上心，是想找对的、不想凑合。你和爸的心事我懂，但这个心事别背在你们身上——我日子过得挺好，这本身就该让你们放心才对。

📌 **发送建议**
是真焦虑不是施压，先接住她的心、再把边界温柔立住，掀桌版慎用。

## 安装

对着你的 agent（Claude Code / Codex / Cursor / OpenClaw…）说一句就行：

> 帮我把这个 skill 装上：https://github.com/SilentFleetKK/zuiti-cuihun

或者命令行一条：

```bash
npx skills add SilentFleetKK/zuiti-cuihun
```

装好后，把长辈那条消息直接贴给它：

```text
> /催婚 [粘贴我妈/我姨发来的消息]
> 我妈又催了，这条我该怎么回：[消息]
```

你会拿到固定输出：潜台词翻译（先分清压还是爱）→ 误读风险 → 三档回复 → 长期策略 → 发送建议。

## 它专治哪几套

| 套路 | 长辈原话 | 它帮你 |
|---|---|---|
| 横向比较 | 你看别人孩子都两个了 | 不接尺子，不辩解 |
| 贬低选择 | 眼光别太高、你挑什么挑 | 把"挑"翻译成"负责" |
| 卖年龄 | 我们年纪都上来了 | 先接焦虑，再拆义务 |
| 道德包装 | 都是为你好、就这一个心事 | 认下爱，但节奏我定 |
| 降门槛 | 见一面怎么了 | 见不见 + 什么条件，拆开回 |
| 要交代 | 什么时候带回来、给个准话 | 给确定感，不给时间表 |

完整识别表和应对原则见 `SKILL.md`。
